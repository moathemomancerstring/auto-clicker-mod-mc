## 📖 About

Auto Clicker Mod fires continuous left or right clicks at a configurable CPS rate, useful for AFK grinding, tree farming, and performance testing.

## ✨ Features
<a name="features"></a>

- **Configurable CPS** — 1 to 20 clicks per second.
- **Left & Right Click** — separate toggles for each button.
- **Break Mode** — auto-holds to break blocks continuously.
- **Attack Mode** — targets entities in front for mob grinding.
- **Toggle Key** — start and stop instantly.
- **HUD Indicator** — shows active CPS on screen.
